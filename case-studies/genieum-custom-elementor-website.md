# Genieum Custom Elementor Website

**Website:** https://genieum.com/  
**Role:** WordPress Developer / Elementor Pro Developer  
**Project Type:** Figma to WordPress Development

---

## Project Overview

Genieum is a custom WordPress website built from a provided Figma design. The goal of the project was to translate the approved visual design into a clean, responsive, and modern Elementor Pro website while keeping the layout accurate across desktop, tablet, and mobile devices.

---

## My Role

My role was to convert the Figma design into a functional WordPress website using Elementor Pro. I focused on accurate layout recreation, clean spacing, responsive structure, and custom CSS adjustments where Elementor’s standard styling options were not enough.

---

## Tools Used

- WordPress
- Elementor Pro
- Figma
- Custom CSS
- Responsive Web Design

---

## Development Approach

The build was developed with attention to visual accuracy, layout consistency, and mobile responsiveness. I recreated the main sections from the Figma design in Elementor Pro, refined spacing and alignment, and used custom CSS for styling details that required more control.

---

## Key Work Completed

- Converted Figma layouts into Elementor Pro sections
- Built responsive desktop, tablet, and mobile layouts
- Applied custom CSS for unique styling and visual polish
- Maintained clean spacing and consistent design hierarchy
- Delivered a modern WordPress website aligned with the original design direction
