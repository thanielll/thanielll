# Genieum Case Study Images

Upload Genieum case study images in this folder using these exact file names so the portfolio can pick them up cleanly:

1. `Project Thumbnail.jpg`
   - Main image used on the case study archive card, homepage project card, and single case study hero.
   - Recommended size: 1600 × 900px or larger.

2. `Home Page.jpg`
   - Main homepage/full-page preview.

3. `Hero Section.jpg`
   - Hero section close-up or top fold preview.

4. `Dashboard Section.jpg`
   - Dashboard/interface section preview.

5. `Mobile Responsive.jpg`
   - Mobile or responsive layout preview.

Current fallback file:

- `genieum-thumbnail.svg`

This fallback keeps the case study from showing broken images while the final JPG files are not uploaded yet. Once you upload `Project Thumbnail.jpg`, the site will use it automatically for the card and hero preview.
