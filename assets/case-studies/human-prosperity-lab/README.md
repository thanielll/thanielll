# Human Prosperity Lab Website Build Assets

Upload approved case study visuals in this folder using these exact filenames so the portfolio can pick them up cleanly later.

## Recommended image files

- `Project Thumbnail.jpg` — main featured/archive card image
- `Homepage Preview.jpg` — homepage desktop screenshot
- `Mobile Preview.jpg` — mobile screenshot
- `Brand Guidelines.jpg` — brand guideline preview image
- `About Section.jpg` — optional internal/section screenshot
- `Contact Section.jpg` — optional internal/section screenshot

## Optional PDF files

- `Approved HPL Brand Guidelines.pdf` — brand guideline PDF, if approved for public viewing

## Notes

- Use JPG for screenshots whenever possible.
- Keep names exactly as written above, including capitalization and spaces.
- If a file is not uploaded yet, the portfolio will use a styled placeholder preview.
