## Maintenance Rules

- Do not replace the working HTML/CSS/JS structure in one large refactor.
- Do not rename live image folders or filenames unless every reference is updated and tested.
- Keep design-related styles in CSS unless the current script intentionally injects section-specific styles.
- When cleaning up, work in a branch first and test desktop, tablet, mobile, and browser console before merging.
- Keep case study screenshots and PDFs organized inside `assets/case-studies/`.
- Use lowercase kebab-case filenames for new assets moving forward.
