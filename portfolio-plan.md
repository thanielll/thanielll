# GitHub Portfolio Plan

This file is a working plan for turning this GitHub profile into a professional portfolio.

---

## Main Goal

Use GitHub as a credibility layer for web design and WordPress development work.

The profile should show:

- What I do
- What tools I use
- What types of websites I build
- How I document projects
- How I think through design, SEO, and development

---

## Recommended Repositories to Create

### 1. portfolio-website
A live GitHub Pages portfolio website.

Suggested structure:

```txt
portfolio-website/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── screenshots/
└── case-studies/
```

---

### 2. website-case-studies
A repo for documenting real projects when code cannot be shared.

Suggested folders:

```txt
website-case-studies/
├── dental-practice-website/
├── business-landing-page/
├── ecommerce-product-page/
└── website-redesign/
```

Each folder should include:

- README.md
- screenshots
- design notes
- tools used
- project outcome

---

### 3. ui-section-library
A repo for reusable UI sections.

Examples:

- Hero sections
- CTA sections
- FAQ sections
- Pricing tables
- Service cards
- Testimonial blocks
- Contact sections

---

### 4. css-snippets
A repo for useful CSS snippets used in Elementor and WordPress projects.

Examples:

- Fee table styling
- Accordion styling
- Sticky header effects
- Gradient overlays
- Hover cards
- Responsive spacing helpers

## Case Study Checklist

Before publishing a case study, include:

- Clear project title
- Short overview
- My role
- Tools used
- Main goal
- Screenshots
- Responsive notes
- SEO/content notes
- Live link if available
- Honest notes on scope or limitations
